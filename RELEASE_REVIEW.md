## Name and identity

[NewPipe e.V.'s trademark policy](https://newpipe-ev.de/policy/trademark/) distinguishes development source and short-lived test builds from end-user distributions. Its policy says modified downstream apps should not use the NewPipe mark in the name of an end-user download. Therefore **NewPipe-Kids is a development repository name, not an approved public release name**. Before an end-user release, choose a distinct app name and identity, replace upstream-branded icons and other marks as appropriate, and preserve clear attribution without implying endorsement. The policy specifically treats APKs uploaded to GitHub Releases as end-user facing.

The current project and README identify this as independent and not endorsed by TeamNewPipe. No end-user release is prepared by this review. Recheck the policy and the exact distribution obligations before publishing.
